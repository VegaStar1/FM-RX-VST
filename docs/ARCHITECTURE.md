# FM·RX — архитектура (итерация 1)

## Модули
| Модуль | Назначение | Потоки |
|---|---|---|
| `Parameters.h` | ID и диапазоны параметров VST3 (стабильные) | любой |
| `Engine/FmBand` | весь диапазон: 8 передатчиков, эфир, приёмник, AFC, динамик, выход | аудио |

| `Dsp/Receiver` | ПЧ-фильтр, демодулятор QUAD/PLL, стереодекодер с ФАПЧ, децимация, деэмфазис, бленд, soft mute, hi-cut | аудио |
| `Dsp/Polyphase` | полифазные интерполятор ×L и дециматор ÷L (Кайзер) | аудио |

| `PluginProcessor` | параметры, состояние, `processBlock`, seek | аудио + message |
| `PluginEditor`, `UI/*` | интерфейс | message |

## Две частоты дискретизации
Звук хоста (44.1–192 кГц) и «эфир» Fs_air = L × Fs_host ≥ 380 кГц (44.1 -> ×9, 48 -> ×8, 96 -> ×4).
Эфир считается в **комплексной полосе вокруг частоты настройки**: станция с частотой f_k имеет отстройку
Δ_k = f_k − f_гетеродина и в полосе эфира выглядит как ЧМ-сигнал на частоте Δ_k.

Станция участвует, только если её спектр (±130 кГц) не может «завернуться» в полосу ПЧ:
|Δ_k| < Fs_air − 130 кГц − 100 кГц − 10 кГц (≈144 кГц при 48 кГц). Последние 30 кГц зоны — плавное появление.
Дальние станции DSP не тратят. Поэтому соседка в 100 кГц слышна (как в жизни), а в 200 кГц — нет.

## Цепочка на каждый сэмпл хоста
1. TUNE сглаживается (40 мс); гетеродин = TUNE + дрейф + поправка AFC.
2. Для станций в зоне: отстройка, вес зоны, коэффициент замираний; `pushHost(L, R)`:
   ФНЧ 15 кГц (Баттерворт 4) -> преэмфазис -> лимитер -> M = (L+R)/2, S = (L−R)/2 -> интерполяторы ×L.
3. L раз на частоте эфира: MPX = 0.9·(M + S·sin 2θ) + 0.1·sin θ (θ — фаза пилота, 38 кГц = удвоенная фаза);
   фаза несущей += Δ_k + 75 кГц·MPX; сумма станций × замирания -> многолучёвость, импульсы, шум ->
   ПЧ-фильтр (Баттерворт 8 по I и Q) -> демодулятор:
   * QUAD: arg(x[n]·conj(x[n−1])) — приращение фазы (как в radiofm.demod);
   * PLL: ФАПЧ 2-го порядка с фазовым детектором atan2, петля ~40 кГц (как radiofm.demod2).
   -> ФАПЧ по пилоту 19 кГц (полоса ~30 Гц) -> L+R (минус восстановленный пилот, режекция 19 кГц) и
   L−R = MPX·2 sin 2θ -> ФНЧ 15 кГц (Баттерворт 6) -> дециматоры ÷L.
4. На частоте хоста: бленд стерео по захвату пилота и SNR, деэмфазис, hi-cut и soft mute по SNR и
   детектору отстройки, окраска динамиком, выходной уровень, мягкий потолок, защита от NaN/Inf.
5. AFC копит поправку (±50 кГц) только когда ручка стоит 0.25 с и SNR > 14 дБ.

Оценка SNR: мощность в ПЧ минус известная мощность шума эфира в полосе ПЧ.
Задержка (≈32 сэмпла при 48 кГц, интерполятор + дециматор) сообщается хосту.

## Потоки и файлы
Как в FREQUENCY-VST: UI -> `loadFileAsync` -> ThreadPool (декодирование, ресемплинг к частоте хоста,
нормализация −18 dBFS RMS) -> `callAsync` -> новый `StationSnapshot` атомарно публикуется.
Аудиопоток в начале блока делает `acquire()`; старые снимки освобождает таймер на message-потоке.
Пустой файловый слот не излучает несущую.


## Проверки
* `tests/test_fm.cpp` — точная настройка (THD+N ≈ 0.17 %), стереоразделение (≈31 дБ), моно-станции,
  расстройка, слабый сигнал (громкость сохраняется, растёт шум), soft mute, PLL, тяжёлый канал, AFC,
  соседние станции, нагрузка CPU (≈13 % ядра при трёх станциях в зоне).
* `tests/test_player.cpp` — подготовка файлов, бесшовный луп, смена буфера.
* `tests/plugin_check.cpp` (`-DFMRX_BUILD_CHECK=ON`) — процессор в консольном хосте: звук, seek,
  сохранение/восстановление, снимок интерфейса.
