FM RX @VERSION@ - 8-station FM band receiver (VST3) by NUWMUN
==============================================================

WINDOWS (10/11, 64-bit)
  1. Run FM-RX-@VERSION@-Windows-Setup.exe and click Install.
     If Windows shows "Windows protected your PC", click
     More info -> Run anyway.
  2. The plug-in is installed to
     C:\Program Files\Common Files\VST3\FM RX.vst3
  3. Open your DAW and rescan plug-ins.

MACOS (10.13 or later, Apple Silicon and Intel)
  1. Open FM-RX-@VERSION@-macOS.pkg and follow the steps.
     If macOS says the developer cannot be verified, right-click
     the file -> Open (or System Settings -> Privacy & Security ->
     Open Anyway).
  2. The plug-in is installed to
     /Library/Audio/Plug-Ins/VST3/FM RX.vst3
  3. Open your DAW and rescan plug-ins.

FM RX shows up in your DAW as an effect by NUWMUN.
A short help window opens on first launch.

Full manual: FM-RX-@VERSION@-Manual-EN.pdf (Russian: FM-RX-@VERSION@-Manual-RU.pdf).
