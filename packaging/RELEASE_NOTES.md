## FM RX @VERSION@

8-station FM band receiver · VST3 · Windows & macOS · by NUWMUN

### What's new in @VERSION@
- **Hand-over after a 1-SHOT:** adjustable **PAUSE** before the automatic search (0–5 s) and **HAND-OVER NOISE** (0–100 %). A finished station no longer cuts to a harsh burst of noise — the hiss now rises smoothly as the dial moves away.
- **Keep Tune automation:** search, scan and the hand-over never write the TUNE parameter, so automation in Ableton Live and other DAWs stays on.
- **Noise colour:** tone (dull ↔ bright), frequency and sharpness of the hiss. Clean stations are not affected.
- English is now the default interface language; Russian is one click away in Settings.
- Updated manual and in-plugin help; six factory presets got their own noise colour.

### 🛠 Install

**Windows**
1. Run `FM-RX-@VERSION@-Windows-Setup.exe` and click **Install**.
   If Windows shows "Windows protected your PC", click **More info → Run anyway**.
2. The plug-in goes to `C:\Program Files\Common Files\VST3\FM RX.vst3`.
3. Open your DAW and rescan plug-ins.

**macOS**
1. Open `FM-RX-@VERSION@-macOS.pkg` and follow the steps.
   If macOS says the developer cannot be verified, right-click the file → **Open** (or System Settings → Privacy & Security → **Open Anyway**).
2. The plug-in goes to `/Library/Audio/Plug-Ins/VST3/FM RX.vst3`.
3. Open your DAW and rescan plug-ins.

FM RX shows up as an **effect** by **NUWMUN**. A short help window opens on first launch; the full manual is under the gear button → Help.
